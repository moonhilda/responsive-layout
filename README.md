# Responsive Layout

A Figma skill that prepares responsive layouts using spacing variables,
auto-layout, width constraints, Fill, and Wrap.

## Workflow

1. Prepare and validate responsive source frames.
2. Get user approval.
3. Create and validate Tablet and Mobile versions.

## Install in Codex

Ask Codex:

> Install the responsive-layout skill from https://github.com/moonhilda/responsive-layout/tree/main/responsive-layout

## Requirements

- Access to the target Figma file and its design-system variables.
- A Figma connection that supports editing.
